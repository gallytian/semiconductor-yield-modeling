项目目标

半导体晶圆良率建模分析系统，覆盖从数据准备、良率回归预测、低良率拦截、SHAP根因分析、SPC统计过程控制、DOE实验设计、贝叶斯优化到报表生成的完整工业数据分析流程。

  • modeling/spc_analysis.py — Xbar-R控制图 + 过程能力分析(Cp/Cpk/Pp/Ppk)
  • modeling/optimize.py — DOE(LHS) + 贝叶斯优化(GP+EI) + Pareto多目标优化

  • generate_dashboard.py — 动态Dashboard，从JSON读取优化结果生成可交互页面

概览数据流与业务闭环

完整业务流程
  1. 数据准备：CSV(1250×28) → 18个数值工艺参数 + 4个机台one-hot → 时间切分80/20
  2. 良率回归：XGBoost / RandomForest 预测 yield → R²/RMSE 评估精度
  3. 低良率识别：XGBClassifier 二分类(yield<0.35) → Top-k拦截覆盖率曲线
  4. SHAP根因：TreeExplainer → 定位驱动良率的关键参数(CD/oxide/vth)
  5. SPC控制：对关键参数绘制Xbar-R控制图 → 计算Cp/Cpk/Pp/Ppk → 识别失控点
  6. 工艺优化：代理模型(RF) → LHS采样 → 贝叶斯优化(GP+EI) → Pareto前沿(yield+Cpk)
  7. 报表输出：静态报表(6类HTML) + 动态Dashboard(可切换视图)

业务背景

为什么对比两个模型？

XGBoost（梯度提升树）和RandomForest（随机森林）都是集成学习方法，但原理不同：RF是bagging（并行训练多棵树取平均），XGBoost是boosting（串行训练，每棵树修正前一棵的残差）。对比两者可以找到更适合当前数据的模型。
