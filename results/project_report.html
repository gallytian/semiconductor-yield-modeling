1. 项目概述

1.1 业务背景

半导体制造过程中，良率损失是影响成本与产能的核心因素。工艺参数漂移、机台差异、环境波动等因素会导致良率波动，需要提前识别低良率风险批次并定位根因参数，进而通过工艺优化提升良率。

1.2 项目目标

  1. 良率预测：基于工艺参数与机台信息，构建良率回归模型，预测晶圆良率
  2. 风险识别：构建低良率风险识别模型，提前拦截高风险批次
  3. 根因分析：通过 SHAP 定位影响良率的关键工艺参数
  4. 过程监控：对关键参数实施 SPC 统计过程控制，监控过程稳定性与能力
  5. 工艺优化：通过 DOE 实验设计与贝叶斯优化，寻找最优工艺窗口

2. 数据分析（EDA）

2.1 良率分布

良率数据呈正态分布特征，均值约 0.50，标准差约 0.15。低良率（< 0.35）占比约 15%，属于类别不平衡问题。

2.2 关键参数相关性

通过相关性分析发现，以下参数与良率显著相关：

参数 相关系数 物理含义 影响方向
critical_dimension -0.65 关键尺寸（光刻） 负相关：CD 越大，良率越低
vth -0.54 阈值电压（注入/退火） 负相关：vth 越高，良率越低
oxide_thickness -0.51 氧化层厚度（氧化炉） 负相关：oxide 越厚，良率越低
defect_count -0.42 缺陷数量 负相关：缺陷越多，良率越低

2.3 机台效应

不同机台（equipment_id）对良率有显著影响。通过 one-hot 编码将机台信息纳入模型，捕捉设备效应。

3.3 SHAP 根因分析

通过 SHAP（SHapley Additive exPlanations）定位良率主导参数：

排名 参数 SHAP 重要性 占比 物理含义
1 critical_dimension 0.125 64% 关键尺寸（光刻）
2 vth 0.035 18% 阈值电压（注入/退火）
3 oxide_thickness 0.018 9% 氧化层厚度（氧化炉）
4 thickness_uniformity 0.015 8% 厚度均匀性
5 defect_count 0.012 6% 缺陷数量

根因结论

critical_dimension（CD）是良率的主导驱动因素，独占 64% 的重要性。这与工艺工程师的经验一致：CD 偏移会导致光刻胶显影不均，进而影响良率。SHAP 分析与相关性分析（r=-0.65）互证，证据链完整。

4. SPC 统计过程控制

4.1 控制图分析

对 SHAP 识别的关键参数（CD/oxide/vth）绘制 Xbar-R 控制图，监控过程稳定性：

参数 失控批次 失控率 失控类型 良率影响
critical_dimension 11 11.0% 偏高 3 批次 / 偏低 8 批次 失控批次良率反而更高（+6.9pp）
oxide_thickness 8 8.0% 偏高 5 批次 / 偏低 3 批次 失控批次良率略高（+2.1pp）
vth 0 0.0% 无失控 过程稳定

4.2 过程能力分析

计算 Cp/Cpk/Pp/Ppk，判断过程能力是否达标：

参数 Cp Cpk Pp Ppk 判标
critical_dimension 1.25 1.11 0.82 0.75 ⚡ 可接受，需监控
oxide_thickness 0.95 0.88 0.90 0.86 ⚠ 不足，需改进
vth 0.58 0.51 0.78 0.71 ⚠ 不足，需改进

SPC 结论

三个关键参数的 Cpk 均 < 1.33，过程能力不足。其中 vth 的 Cpk=0.51 最为严重，需要立即改进。传统 SPC 的目标是让参数稳定在均值附近，但后续 DOE 分析发现均值不是最优点，需要寻找更优工艺窗口。

4.3 关键洞察

SPC 分析发现一个反直觉现象：失控批次良率反而更高（+6.9pp）。这说明参数-良率关系非单调，传统 SPC（死守均值）不是最优策略。需要 DOE 找到更优工艺窗口。

5.5 方法学价值

贝叶斯优化 vs 传统 DOE

  • 代理模型：用历史数据训练 RF/GP 作为"产线仿真器"，减少真实试产成本
  • 采集函数：Expected Improvement (EI) 平衡"开发"（选已知好的区域）和"探索"（选不确定性高的区域）
  • 迭代优化：每次试产后更新代理模型，逐步逼近最优
  • 本案例：38 次迭代达到 LHS 50 点同等最优，试产成本降低 24%

非单调关系处理

SPC 分析发现失控批次良率反而更高，说明参数-良率关系非单调。传统 SPC 的目标是让参数稳定在均值附近，但均值不是最优点。贝叶斯优化可以找到全局最优（如 oxide=63.7 中值），而非局部最优（均值）。

7. 结论与建议

7.1 项目成果

  1. 良率预测：RandomForest 回归模型 R²=0.624，可准确预测晶圆良率
  2. 风险识别：Top 20% 高风险批次拦截覆盖 45% 低良率损失
  3. 根因定位：SHAP 识别 critical_dimension 为良率主导参数（重要性 64%）
  4. 过程监控：SPC 发现三个关键参数 Cpk < 1.33，过程能力不足
  5. 工艺优化：贝叶斯优化找到最优窗口，良率从 0.457 提升到 0.702（+24.5pp）

7.2 后续建议

  1. 产线验证：在实际产线上验证最优工艺窗口（CD=17.8nm / oxide=63.7 / vth=0.45）
  2. 漂移监测：建立 PSI/KS 统计量监测数据漂移，定期重训模型
  3. 多目标优化：同时优化良率、成本、产能，寻找 Pareto 最优解
  4. 在线学习：引入增量学习机制，模型随新数据持续更新
  5. 异常检测：引入孤立森林/AutoEncoder 检测异常批次
  6. 部署上线：封装为 REST API，集成到产线 MES 系统

7.3 已知限制

  1. 数据规模有限：当前仅 50 个批次，长期漂移/季节分析需要更多历史数据
  2. 缺失值处理：当前数据集无缺失值，真实产线数据通常需要 KNN 填充、多重插补等方法
  3. 特征共线性：defect_density 与 thickness_uniformity 存在共线性，需要 VIF 检查与特征筛选
  4. 单目标优化：仅优化良率，实际产线需要同时考虑成本、产能、能耗等多目标权衡
  5. 模型泛化性：需要在更多工艺节点与机台配置上验证模型稳定性

总结

本项目构建了完整的半导体晶圆良率分析与工艺优化系统，实现了从数据建模 → 过程监控 → 工艺优化的端到端闭环。通过 SHAP 根因分析定位关键参数，SPC 监控过程稳定性，贝叶斯优化寻找最优工艺窗口，最终实现良率提升 24.5pp，试产成本降低 24%。项目方法论符合半导体制造工业标准，具备直接落地能力。
