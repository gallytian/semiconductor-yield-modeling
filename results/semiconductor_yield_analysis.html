一、数据源与背景

项目内容
数据集名称Semiconductor Yield（Semiconductor Wafer Yield and Process Parameter Dataset）
来源Kaggle（ayyappanmarimuthu/semiconductor-yield，2026 年发布）
数据形态1250 片晶圆 × 28 列（批次/机台上下文 + 18 个工艺与电测参数 + 良率）
工艺覆盖蚀刻（Etch）、光刻（Lithography）、沉积（Deposition）、离子注入（Implant）四大工序
技术节点7nm / 10nm / 14nm / 22nm / 28nm 五节点
产品类型ASIC / CPU / FPGA / GPU / Memory
时间范围2023-01-01 ~ 2023-02-19（50 天，50 批次）
缺失值0（数据干净）
目标变量yield（晶圆良率，0~1 连续值，均值 0.457）
数据性质说明：该数据集为 Kaggle 上用于分析练习的合成数据——工艺参数名、机台编号、列结构与流程约定均参考真实半导体制造实践，但数值为模拟生成（参数-良率关系比真实产线更"理想化"）。适合方法学演示与流程训练；面试展示时需如实说明这一点。

业务背景：半导体制造中，晶圆良率（单片晶圆上合格芯片占比）直接决定产品线商业价值。良率损失来自设备健康、工艺参数漂移、产品-节点匹配的复杂交互。本报告复现真实 Fab 良率调查的分析流程：设备性能对标 → SPC 过程控制 → 参数-良率相关 → 低良率批次根因排查。

三、时间分析

按周：批次量与平均良率。50 天内批次节奏均匀，良率周间波动（无强趋势）——短期数据不足以做长期漂移分析，但可作为基线。

四、良率分布：节点 × 产品

节点 × 产品平均良率热图（空格 = 该节点不生产该产品，反映真实机台资格约束）：10nm 表现最好（CPU/GPU 0.62），22nm 最差（GPU 0.315），14nm 全产品线系统性偏低。
良率分组：Low<35% 占 396 片（30%）、Mid 437 片、High≥50% 417 片（46%）。

五、参数-良率相关性（根因线索）

18 个工艺/电测参数与良率的 Pearson 相关：critical_dimension（r=-0.653)、vth（r=-0.541）、oxide_thickness（r=-0.507）为最强负相关——参数越大良率越低。

七、机台良率对比

各工序机台平均良率（误差棒 = 机台间 std）：机台间差异存在但有限——方差（稳定性）而非均值是主要风险信号，均值达标但方差大的机台应优先检修。

八、根因量化：随机森林特征重要性

RF 回归特征重要性（训练 R²=0.86）：critical_dimension 独占 64.4%，远高于第二名（vth 9.9%）——与相关性分析互相印证，证据链闭合。
低良率组（<35%）vs 高良率组（≥50%）关键参数对比（均值）：
critical_dimension：低组 27.751 vs 高组 20.917（约 5nm 系统偏差）｜ vth：0.679 vs 0.596｜ oxide_thickness：59.793 vs 53.865。

九、业务结论与建议

① CD 控制是首要良率杠杆：critical_dimension 相关性（r=-0.65）+ 特征重要性（64.4%）+ 分组差异（5nm 偏移）三方法互证 → 优先收紧光刻 CD 规格与在线量测监控；
② 14nm 节点级问题：全产品线良率 <37% → 排查配方/工艺条件而非单台设备；
③ SPC 联动：22nm oxide_thickness OOC 率最高 → 建立自动 Hold 触发；OOC 批次应与设备维护日志交叉排查；
④ 机台稳定性监控：方差超标的 Watch 机台提前安排保养，防劣化为故障机台；
⑤ 建模落地：yield 回归（R²≈0.6）+ 低良率分类（Top-k 拦截），可对接 DOE/贝叶斯优化寻优 CD 工艺窗口（与 smart-process-optimizer 项目闭环）。
