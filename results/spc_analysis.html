一、SPC 原理与工业背景

半导体产线需要实时监控关键工艺参数是否"受控"：

  • 控制图（Control Chart）：判断过程是否稳定，有无异常波动
  • 过程能力（Cpk / Ppk）：衡量过程输出是否满足规格要求
    • Cpk（短期能力）：基于组内变异（within-subgroup），反映"最佳状态"
    • Ppk（长期性能）：基于整体变异（overall），反映"实际表现"
    • Cpk > 1.33 通常认为过程能力充足（6Sigma 标准）
  • FDC（Fault Detection & Classification）：当参数超出控制限（OOC），自动 Hold 批次，等待工艺工程师排查根因
Xbar-R 控制图原理：按批次（lot）分组，每个 lot 包含多片晶圆（wafer）。Xbar 图监控批次均值是否漂移，R 图监控批次极差（波动）是否稳定。控制限 = 均值 ± 3σ（基于子组内变异估计）。

⚠ 关键洞察：参数-良率关系非单调
失控批次良率反而更高（+6.9pp），说明参数-良率关系不是简单的"偏离均值就良率下降"。

业务含义：
  • 传统 SPC（死守均值）不是最优策略，可能错过更优工艺窗口
  • 这正是 DOE + 贝叶斯优化的价值：不追求"稳定在均值"，而是"找到最优"
  • optimize.py 用贝叶斯优化找到最优窗口（CD=17.8nm / oxide=63.7 / vth=0.45），良率从 0.457 提升到 0.702（+24.5pp）

五、业务闭环：SPC → DOE → 贝叶斯优化

完整的工业落地流程：

  1. main.py：SHAP 识别关键参数（CD / oxide / vth）
  2. spc_analysis.py：SPC 监控 + Cpk 评估
    • 发现 oxide_thickness（Cpk=0.88）和 vth（Cpk=0.51）能力不足
    • 识别失控批次，模拟 FDC 自动 Hold
  3. optimize.py：DOE + 贝叶斯优化找最优工艺窗口
    • 代理模型（RF）：测试 R²=0.623
    • DOE（LHS）50 点试产：最优 yield=0.703
    • 贝叶斯优化 38 点：最优 yield=0.702（试产成本 -24%）
    • 最优窗口：CD=17.8nm / oxide=63.7 / vth=0.45
  4. 业务价值：良率从 0.457 提升到 0.702（+24.5pp），试产成本降低 24%
面试话术："我们在项目中实现了完整的 SPC 体系：用 Xbar-R 控制图监控关键参数稳定性，计算 Cpk 评估过程能力，发现 oxide 和 vth 能力不足。关键洞察是：失控批次良率反而更高，说明参数-良率关系非单调，传统 SPC 不是最优策略。所以我们结合 DOE + 贝叶斯优化找到更优工艺窗口，良率提升 24.5pp。"

六、Cpk 与 Ppk 的区别（面试高频题）

指标 Cpk（短期能力） Ppk（长期性能）
定义 基于组内变异（within-subgroup），反映过程的最佳状态 基于整体变异（overall），反映实际表现
σ 估计 σ_within = R_bar / d2（d2 是常数，n=5 时 d2=2.326） σ_overall = 整体标准差（所有数据）
适用场景 短期过程能力评估（如设备验收、工艺验证） 长期过程性能评估（如量产监控）
判标 Cpk ≥ 1.33 为充足 Ppk ≥ 1.33 为充足
本数据表现 Cpk > Ppk 说明过程存在组间漂移（批次间变异 > 批次内变异），需要排查设备/批次效应
